Star Jump

游戏介绍

Star Jump 是一款极简黑色风格的横版跑酷游戏。玩家操控一个白色圆角矩形小人，在星空背景下穿越8个精心设计的关卡。小人有着标志性的黑色圆形眼睛，奔跑时会留下从大到小渐变的白色拖尾圆点，跳跃时身体会有挤压拉伸的非线性动画，整体手感丝滑流畅。

游戏操作十分友好，左下角是圆形虚拟摇杆控制左右移动，右下角是写着"跳"的圆形跳跃按钮，同时也支持键盘操作。支持二段跳，在空中按跳跃键可以再跳一次。关卡难度循序渐进，平台宽敞、间距适中，即使手残党也能轻松上手。每关散布着上下浮动的金色金币，收集时会发出清脆的音效。

死亡机制非常宽容，碰到尖刺或掉出屏幕后会立即在出生点复活，死亡次数会计入统计但游戏不会中断，让玩家可以无压力地反复尝试。通关后可以选择进入下一关、重新开始或返回主界面，已解锁的关卡可以在选关界面自由选择。

所有按钮均为黑色圆角设计，图标和图形全部用 SVG 和 CSS 纯代码绘制，没有任何 emoji。背景是闪烁的星星粒子，营造出深邃的太空氛围。游戏还配备了完整的音效系统，跳跃、收集金币、死亡、通关和按钮点击都有独特的合成音效，使用 Web Audio API 实时生成，无需加载任何外部音频文件。
